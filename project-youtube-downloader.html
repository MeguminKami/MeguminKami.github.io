Project Story

The driving idea was to make a technically capable download tool that feels approachable.

⚠ Problem

Downloading YouTube content often means dealing with unreliable browser extensions, confusing web tools, or command-line interfaces that expose too much complexity at once.

  • No clear quality or format selection
  • No playlist handling to merge videos
  • No real-time feedback during long downloads
💡 Design Goal

Build a desktop app with a guided, dialog-driven workflow. Each step should be focused: add a URL, configure the download, watch it run.

  • Paste a YouTube URL
  • Configure download options
  • Monitor download progress
✅ Solution

Using an URL-driven system the app fetches metadata and available formats from YouTube, then guides the user through a structured flow of dialogs to configure and execute the download with real-time feedback.

  • Dependency installer with live logs
  • Dynamic format fetching for single videos
  • Playlist options to merge or download separately
  • Real-time progress dialog with speed, ETA, and size metrics

Key Features

📹

Video Downloads

Download single YouTube videos in MP4 with quality selection based on dynamically fetched available formats.

🎵

Audio Extraction

Audio-only mode extracts MP3 with selectable bitrate: 320 kbps, 192 kbps, or 128 kbps.

📋

Playlist Support

Download entire playlists as separate files or merge all videos into one output with a custom filename.

🔍

Dynamic Format Discovery

For single videos, the app fetches actual available formats from YouTube metadata and marks incompatible options as disabled.

📊

Real-Time Progress

Live speed, ETA, downloaded size, and total size displayed during every active download for full transparency.

🔧

Guided Dependency Installer

First-run installer detects missing yt-dlp and walks through setup with live logs, retry on failure, and auto-close on success.

📥

Queue Workflow

Items are validated and added to a download queue before processing starts, supporting both video and audio tasks in the same session.

🌙

Dark / Light Theme

A reactive theme system switches between deep navy dark mode and soft gray light mode, updating all UI components globally.

End-to-End Workflow

The app follows a linear, focused flow from launch to completed download. Each step is handled by a dedicated dialog, keeping user decisions scoped and clear.

1

Launch the app

App starts and checks for required dependencies. If yt-dlp is missing, the Installer Dialog opens automatically.

2

Paste a YouTube URL

Enter a single video or playlist URL. The app reads metadata in the background and prepares the options flow.

3

Configure the download

The Options Dialog opens with format, quality, and playlist choices. For single videos, available formats are fetched dynamically from YouTube.

4

Add to queue

Validated queue items are created with all metadata — URL, type, quality, playlist flags, merge behavior, and title — ready for download.

5

Watch the progress

The Progress Dialog shows live download telemetry: current item, overall percentage, speed, ETA, and downloaded vs total size.

Three Core Dialogs

Each dialog handles one focused task, keeping the UX clean and the state transitions clear regardless of whether the user is a first-time setup or an experienced power user.

⚙

Installer Dialog

Appears on first run if yt-dlp is not found. Runs the installation in a background thread and streams live logs to the user. Shows retry and exit options on failure, and auto-closes on success.

📋

Options Dialog

Centered modal with scrollable card sections. Lets the user choose download type (video/audio), quality or bitrate, and playlist behavior (separate files or merged). Dynamic format loading for single videos.

📊

Progress Dialog

Non-closable modal that tracks the active download. Displays queue status, current item card, overall progress bar, and a stats row with speed, ETA, downloaded size, and total size.

Download Item Model

Every queue entry is built from a structured DownloadItem model that captures both simple fallback and advanced format-specific metadata in one place.

ℹ

Simple vs Advanced Paths

When dynamic format fetching succeeds, the item stores precise format_id values for video and audio streams. When it does not, the item falls back to height-based quality presets (1080p, 720p, 480p, 360p) for a reliable download in all cases.

📹

Video mode

Stores selected format ID, height, quality label, and a merge flag when the chosen stream requires muxing with a separate audio track.

🎵

Audio mode

Stores the selected bitrate (320 / 192 / 128 kbps) and audio format ID, bypassing the video quality flow entirely.

📋

Playlist mode

Separate mode creates one queue item per video. Merge mode creates a single playlist item with an optional custom output filename.

UI & Theme System

The app uses a modern desktop aesthetic with rounded cards, layered surfaces, strong spacing, and an accent-driven blue-violet color system. A ThemeManager stores the current mode and dispatches reactive callbacks to update every UI component simultaneously.

🌌

Dark Theme

Deep navy background, muted blue-slate surfaces, bright cyan-blue and vibrant violet accents, with white primary text.

☀

Light Theme

Soft gray background, white surfaces, preserved blue and purple brand accents adapted for contrast on light backgrounds.

💬

Tooltips

Reusable hover tooltips appear near the cursor, use themed colors, and dismiss on pointer leave — explaining controls without cluttering the UI.

🗗

Modal Positioning

The installer dialog centers relative to the parent window and repositions when the parent moves. Other dialogs center on screen for consistency.

🎯

Technical UX Principles

Long operations (dependency install, format fetch) run on background threads with callbacks marshaled back to the main thread — keeping the UI responsive and the user informed throughout.
