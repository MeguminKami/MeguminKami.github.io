Gerador de Sopas de Letras

The project is built around automatic generation of puzzle page files in LaTeX. Its purpose is to create organized collections of word-search pages with multiple page formats, including both battle-style pages and standard single-puzzle pages.

Latest Update 2025
Type Solo Project
Category Python Terminal Application
Status Complete

Overview

A local menu-driven workflow lets the user choose an output folder, load word pools from the .json directory, pick the page type, set how many pages to create, choose a difficulty level, and then generate a full batch of numbered .tex files for compilation.

Project Story

The core idea is not just puzzle generation, but reliable production of multiple printable formats from the same controlled pipeline.

⚠ Problem

Building puzzle books by hand is repetitive and fragile. Managing varied layouts, keeping word sets consistent, and preparing printable files takes time before the actual book design even starts.

  • Repeated layout work for each page
  • Manual control of word placement and reuse
  • Extra effort to keep the book compilation organized
💡 Design Goal

Create one generator that can produce both battle pages and standard puzzle pages while preserving a consistent output workflow for books, collections, and themed sets.

The emphasis is on multiple layout modes, controlled word selection, and reliable print exports instead of one-off on-screen puzzles.

✅ Solution

The implemented tool loads length-based JSON dictionaries, generates words for each page, places them into constrained grids, fills the remaining cells with difficulty-aware letters, and exports numbered LaTeX files ready for compilation.

  • Batch page generation in one session
  • Reusable LaTeX book structure with main.tex
  • Battle and standard layouts from the same generator core

Supported Page Types

                    

                        

                            
📘

                            
Type A - Battle Page with Details

                            

                                Two 14 x 11 puzzles on the same page, 14 words each, plus battle metadata fields such
                                as date, winner, and time.
                            

                        

                        

                            
⚔

                            
Type B - Battle Page without Details

                            

                                Keeps the paired 14 x 11 competitive layout while removing the extra battle-detail fields.
                            

                        

                        

                            
🗂

                            
Type C - Side Word List

                            

                                A 28 x 17 single-puzzle page with 20 words and a word list placed beside the grid.
                            

                        

                        

                            
📋

                            
Type D - Top Word List

                            

                                A 21 x 20 layout with 30 words and a multi-column list above the puzzle for denser pages.
                            

                        

                        

                            
▣

                            
Type E - Larger Square Battle Grids

                            

                                Two 14 x 14 puzzles on the same page with 16 words each, focused on a larger square format.
                            

                        

                        

                            
↕

                            
Type F - Narrow Vertical Layout

                            

                                A 30 x 12 single-puzzle format with 22 words and a compact side list for tall page designs.
                            

                        

                    

                


                

                    
Generation Pipeline

                    

                        The generator is session-based and optimized for repeated output. Each run is centered around a
                        destination folder and a chosen layout, so the workflow naturally scales from one page to a full booklet.
                    


                    
    
                        
  1. Choose the destination folder for the generated output.
    2. 
                        
  2. Load normalized word lists from the palavras JSON directory.
    3. 
                        
  3. Select the page type that defines the grid and word-list layout.
    4. 
                        
  4. Pick how many pages the session should generate.
    5. 
                        
  5. Choose the difficulty level for filler-letter density.
    6. 
                        
  6. Build a length plan and sample valid words for each page.
    7. 
                        
  7. Place the words into the grid with constrained directions and retries.
    8. 
                        
  8. Export numbered .tex pages such as 1.tex, 2.tex, and 3.tex.

Core Systems

                    

                        

                            

                                
📁

                                
Length-Based Word Pools

                            

                            

                                The palavras folder is organized by word length, with 4.json through
                                8.json providing deterministic pools that are normalized before use.
                            

                        


                        

                            

                                
🔢

                                
Grid Construction Rules

                            

                            

                                Words are placed horizontally or vertically, can appear reversed, may intersect on matching
                                letters, and trigger retries when a valid puzzle cannot be assembled on the first pass.
                            

                        


                        

                            

                                
🎯

                                
Difficulty as Density Control

                            

                            

                                Difficulty changes the probability of filler letters, biasing the background toward letters
                                already present in the chosen words so the grid becomes more visually deceptive.
                            

                        


                        

                            

                                
🔄

                                
Word Reuse Tracking

                            

                            

                                During a generation session the tool tracks which words have already been used, reducing
                                repetition and keeping booklet content more varied page after page.
                            

                        


                        

                            

                                
🖨

                                
LaTeX Output Composer

                            

                            

                                The project is output-oriented: numbered page files and a tailored main.tex
                                work together so the final result is ready for compilation rather than just on-screen viewing.
                            

                        

                    

                


                

                    
Print-Oriented Output

                    

                        The LaTeX side of the project is what turns the generator into a real booklet workflow. It provides
                        the reusable structure that keeps cover pages, puzzle macros, and page iteration consistent.
                    


                    

                        

                            
📕

                            
A5 Template

                            

                                The document structure targets A5 output and includes support for cover and back-cover pages.
                            

                        

                        

                            
📄

                            
Numbered Page Files

                            

                                Each generated page is written as its own numbered .tex file for predictable organization.
                            

                        

                        

                            
⚙

                            
Main Document Updater

                            

                                A folder-specific main.tex is updated to point at the generated pages and total count.
                            

                        

                        

                            
🔀

                            
Shuffle Utility

                            

                                A separate helper script can safely randomize numbered page files using a two-step rename process.
                            

                        

                    


                    

                        
🎯

                        

                            
Strongest Project Idea

                            

                                Gerador de Sopas de Letras is best understood as a flexible generator for printable word-search
                                books and puzzle pages with multiple layout modes, not as a single static puzzle creator.
