DBS Item Shop

DBS Item Shop started as a university PHP/MySQL storefront with authentication, product filtering, account management, and an admin area. This portfolio version now includes a static rebuild in HTML, CSS, and JavaScript so the project can be opened directly on GitHub Pages without any backend.

Latest Update 2026-04-14
Original Stack PHP + PostgreSQL
Static Rebuild HTML + CSS + JS
Status Complete

Overview

The original course project implemented a branded online shop with user accounts, product browsing, server-side forms, and role-based administration. That backend version cannot run on GitHub Pages, so this portfolio now ships with a browser-only demo that preserves the core storefront experience while moving data and session state into localStorage.

Technical Stack

PHP PostgreSQL HTML CSS JavaScript localStorage GitHub Pages
⚠ Problem

The original website depends on PHP includes, session handling, and database queries, so it cannot be deployed as-is on a static host like GitHub Pages.

💡 Approach

Rebuild the interactive parts with reusable frontend state: seeded products, seeded users, cart persistence, login flows, and an admin dashboard that edits local demo data.

✅ Result

A self-contained static website that still demonstrates the original project structure, branding, and user journeys while remaining deployable from this portfolio repo.
